# Paleta PEN (T9.8, 48 cores)

Harmonizada com os gatos (contorno #3b2a38, cremes, laranja, rosa) e a UI noturna. Base: as 32 cores da T9.7
(ate `flower_red`) + 16 extras `x1..x16` escolhidas gulosamente nos sprites do Pixellab (as cores que mais destoavam da
base: roxos das camas, vermelho do coracao, verdes de folhagem, teal, rosa claro). Fonte unica: `palette_pen.json`
(gerado por `assets/tools/build_t98_palette.py`). Todo tile/sprite/fundo do quintal usa so estas cores
(`assets/tools/build_t98_check.py` confere: 0 cores fora). Os periodos do dia (pen_bg_*) sao a mesma paleta multiplicada
pelo tint do periodo.
