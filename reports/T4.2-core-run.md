# T4.2 core da mini-run

## O que mudou
- `core/run.py` (novo): `Run`, `new_run`, `draft_pool`. Exportados em `core/__init__` (`Run`, `new_run`).
- `Content.run` (core/types.py) e `load_content` carregam `data/run.json` (opcional, valida com `run.schema.json`; confere que cada no de batalha/elite/chefe tem inimigo existente).
- `core/cli.py`: removido `DECK_SIZE`, usa `rules.duel.deck_size`. `ui/controller.py` ainda tem seu `DECK_SIZE = 12` (nao toquei).

## API
- `new_run(content, rng) -> Run`: sorteia `start_deck.gatos` gatos adultos (ids `run-1..`); levanta ValueError se `!= rules.duel.deck_size` ou sem `run.json`.
- `run.status`: `map | duel | draft | finished`; `run.result`: `None | "vitoria" | "derrota"`; `run.nodes_cleared`; `run.layer`; `run.node` (no escolhido); `run.draft_options` (ids, distintos); `run.cats`, `run.cards` (ids de efeito/Espirito), `run.deck_size()`, `run.deck_spec()`.
- `available_nodes()` (so em `map`; copias dos dicts do json), `choose_node(id)`, `start_duel(rng, player_first=None) -> Duel`, `finish_duel(duel)`, `pick_draft(index) -> id`, `abandon()` (derrota).
- Fluxo: map -> choose_node -> duel (batalha/elite/chefe) ou draft (descanso, se `rest_draft`). Vitoria em batalha/elite -> draft (`draft_options` ou `draft_options_elite`). Vitoria no chefe -> finished/vitoria (sem draft). Derrota -> finished/derrota. `pick_draft` avanca camada; passar da ultima camada tambem termina em vitoria.
- Erros: `IllegalAction` (estado errado, no fora da camada, indice invalido, duelo sem vencedor ou de outra run).
- `to_dict()/from_dict(content, d)`: JSON-compativel, `version: 1`, inclui deck (gatos + cartas), camada, no, opcoes do draft e estado do rng da run. `to_dict` levanta IllegalAction se houver duelo em andamento (a run so e salva entre duelos; em `status=="duel"` sem `start_duel` chamado salva normal).

## Decisoes
- Sorteio do draft usa o rng da run (`rng.sample` sobre pool em ordem do json); o duelo usa o rng passado a `start_duel` (nao serializado: para replay deterministico a UI guarda sua seed).
- Pool: `pool.effects/specials: true` = todos. Tambem aceito lista de ids.
- Cartas repetidas entre drafts diferentes sao permitidas (deck sem limite).
- Ao fechar o jogo no meio de um duelo, o duelo se perde; ao retomar, a run volta ao no (`status=duel`, e a UI chama `start_duel` de novo).

## UI precisa tratar
Os 4 estados, `result` no fim, mostrar `nodes_cleared`, mapa por camada (todas as conexoes sao totais), chamar `finish_duel` quando `duel.winner` for definido, e capturar IllegalAction.
