# T4.3 - UI da mini-run

Só `ui/` (mais `reports/`). `pytest -q`: 1444 verdes, nenhum teste editado. Fuzz headless: 30 runs com cliques aleatórios + 60 runs completas (IA joga os duelos, cliques aleatórios no mapa/draft, 7 vitórias / 53 derrotas), sem exceção.

## Como ver
- Jogar: `python -m ui --run [--seed N]`.
- Tela isolada (run já no ponto): `python -m ui.demo mapa|draft|descanso|fimrun [--seed N]`; `python -m ui.demo run` = run inteira.
- PNG 3x: `python -m ui --seed 1 --screenshot reports/ui/X.png --cena mapa|draft|descanso|fimrun|fimrun_vitoria|duelrun`. Geradas em `reports/ui/` (mapa, draft, descanso, fimrun, fimrun_vitoria, duelrun). Tudo em 480x270; só o tooltip do nó sobrepõe o mapa (overlay).

## O que mudou
- Mapa: camadas da esquerda para a direita, conexões, ícones por tipo (espadas, espadas+anel = elite, lua = descanso, coroa = chefe), nó disponível pulsa e é clicável, nó atual com anel branco, vencidos com visto e esmaecidos, não escolhidos mais apagados, derrota com X. Tooltip: nome da pessoa, tipo, tamanho do deck e recompensa. Painel com deck da run (gatos/efeitos/Espíritos), nós vencidos, camada, botão ABANDONAR.
- Duelo: o `Controller` de sempre, criado com o `Duel` de `run.start_duel` (deck da run). Painel final tem só CONTINUAR (`finish_duel` e transição).
- Draft: 3 cartas largas (custo, texto completo, ATK/HP e keywords do Espírito, "Já no deck: n"). 1º clique seleciona e mostra ESCOLHER; 2º clique na carta ou ESCOLHER (ou Enter) confirma. Painel com o deck atual. Descanso: título "Descanso: escolha uma carta".
- Fim: vitória/derrota, nós vencidos (`nodes_cleared`) e caminho, cartas escolhidas, fala do inimigo (derrota: quem venceu; vitória: fala do chefe), NOVA RUN / SAIR.
- Atalhos: ESC = desmarcar (draft), cancelar seleção (duelo), pedir abandono (mapa, ou duelo sem seleção; confirma com SIM), sair (fim). Enter = continuar/escolher/nova run. Botão direito = ESC. Sem save/load.
- `ui/controller.py`: `Controller(..., duel=...)` aceita duelo pronto e liga `run_mode` (clique em again/repeat ignorado). `ui/render.py::draw_final` mostra CONTINUAR em `run_mode`. `ui/theme.py`: `NODE_COLOR/NODE_NAME/NODE_LONG`. `ui/__main__.py`: `--run` e as cenas novas. `ui/demo.py`: telas novas.

## API nova (para o agente de testes T4.4)
- `ui/run_controller.py::RunController(content, seed, *, ai_delay=0.5, seed_source=None)` (sem pygame; usa `pygame.Rect` só do layout). Atributos: `run`, `seed`, `duel_ctrl`, `visited` (ids escolhidos), `draft_sel`, `quit_confirm`, `wants_quit`, `abandoned`, `toast`, `end_line`, `draft_from`. Propriedade `screen` (`map|duel|draft|finished`). Métodos: `click(elem)`, `hit(pos)`, `cancel()` (ESC), `confirm_key()` (Enter), `update(dt)`, `again()`, `choose(id)`, `continue_duel()`, `click_draft(i)`, `pick(i)`, `abandon()`; consultas `available_ids()`, `node_rects()`, `node_state(layer, node)` (`done|lost|skipped|available|current|future`), `deck_summary()`, `deck_counts(spirits)`, `draft_cards()`, `draft_title()`, `path_lines()`.
- Elementos: `("node", id)`, `("abandon",)`, `("draft_card", i)`, `("draft_pick", i)`, `("continue",)`, `("new_run",)`, `("quit",)`, `("quit_yes",)`, `("quit_no",)` + os do duelo.
- `ui/layout_run.py`: `node_rect`, `draft_card_rect`, `draft_pick_rect`, `continue_rect`, `end_buttons`, `quit_panel/quit_buttons`, `abandon_rect`, `hit_test(pos, screen, nodes=, n_draft=, selected=, confirm=)`.
- `ui/render_run.py::draw_run_frame(surf, rc, ui)`; `ui/scenes_run.py`: `make(seed, nome)`, `autoplay(rc, rng)`, `play_duel`; `ui/app_run.py`: `run(seed, scene=None)` (async), `screenshot`.
- Seed do duelo i da run = `seed*1000 + i` (determinístico).
