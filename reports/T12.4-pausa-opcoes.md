## Regra de precedência do Esc
O Esc faz primeiro o que já fazia; só abre a pausa quando não há nada a cancelar:
1. Camada de pausa/opções aberta: Esc volta um nível (confirmação -> pausa -> jogo).
2. Edição de nome, doação, ficha aberta no Criatório, confirmação de abandono, confirmação de fim de turno, carta/alvo selecionado no duelo, carta selecionada no draft: cancelam/fecham (inalterado).
3. Telas de volta (Coleção, Breed, Adoção, Novidades, Resultado): Esc volta, como antes (sem pausa).
4. Sem nada a cancelar no Criatório, no mapa da run, no draft sem seleção ou no duelo (inclusive dado/entrada do chefe; no fim do duelo o Esc é ignorado como antes): abre a pausa.
Mudança de comportamento: no mapa, o Esc abria direto "Abandonar?"; agora abre a pausa (ABANDONAR RUN abre a mesma confirmação). No Criatório o Esc ia direto ao menu; agora abre a pausa (SAIR PARA O MENU faz o mesmo). Botão direito não mudou.

## Pausa
Enquanto aberta: `hub/rc/ctrl.update` e `ui.t` não rodam (sem beats, animação, turno inimigo nem respiração), mouse some do jogo; música continua. Itens: Continuar, Opções, Abandonar run (só em run), Sair para o menu (só no Criatório), Sair do jogo (dentro de run pede confirmação, a run se perde como ao fechar a janela).
