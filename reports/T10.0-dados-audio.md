# T10.0 - Dados de audio

Criados: `data/audio.json`, `data/schemas/audio.schema.json`, `data/schemas/examples/audio.example.json`, `data/schemas/examples/invalid/audio.invalid1.json`. Os validadores existentes (`data/validate_data.py`, `validate_examples.py`) pegam o arquivo sozinhos pelo nome; nenhum teste foi editado.

## Regras de caminho
- Relativos a `assets/audio/`. SFX: `sfx/<nome>.ogg`; musica: `music/<nome>.ogg` (schema exige `[a-z0-9_]`, sem `..`).
- `files` com 2 entradas = variacoes sorteadas pela UI (RNG injetado). Variacoes (`_2`): ui_click, card_draw, attack_swing, attack_hit, cat_death, coin, pet. Demais cues: `sfx/<cue>.ogg`.
- Os arquivos reais ainda nao existem; a UI deve tolerar ausencia.

## Catalogo (fixo, conforme pedido)
- UI: ui_click, ui_hover (80 ms), ui_back, ui_denied, coin, ui_open_modal.
- Duelo: card_draw, card_play_cat, card_play_effect, card_play_spirit, attack_swing, attack_hit, leader_hit, cat_death, buff, heal, shield_protected, turn_start_player, turn_start_enemy, energy_up, duel_victory, duel_defeat.
- Run/meta: node_select, draft_pick, rest, adopt, breed_start, kitten_born, level_up.
- Cercado: meow_1..4 (600 ms), kitten_mew (600), purr (2000), bed_settle (800), pet (300).
- Musica: menu_dia, menu_noite, mapa_run, duelo, duelo_chefe (loop); vitoria, derrota (jingles, loop false).
- Contexts: menu->menu_dia, criatorio_dia->menu_dia, criatorio_noite->menu_noite, mapa->mapa_run, duelo->duelo, duelo_chefe->duelo_chefe, fim_vitoria->vitoria, fim_derrota->derrota, colecao->menu_dia, breed->menu_noite, adocao->menu_dia.
- Volumes: musica 0.7, efeitos 0.8; volume de cada cue/faixa 1.0.

## Pendente / duvidas
- Cooldowns (ex.: ui_click 40, card_draw 80, attack_hit 60, buff/heal 100) sao valores tecnicos de anti-spam, ajustaveis. Mapeamento de colecao/breed/adocao para faixas foi escolha minha (nao ha faixa dedicada); Renatho pode trocar.
- O schema usa `version` (como pedido), nao `schema_version` dos outros JSON.
- Schema nao checa que contexts apontam para faixas existentes (o JSON atual confere); uma checagem cruzada em `validate_data.py` seria util.
