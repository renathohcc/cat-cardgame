# T5.3 UI: hub minimo e Colecao (Fase 5a)

## Como rodar
- Jogo: `python -m ui --jogo [--seed N] [--save CAMINHO]` (padrao `saves/save.json`, pasta criada se faltar).
- Telas isoladas (em memoria, nao tocam em `saves/`): `python -m ui.demo menu|colecao|colecao_deck|renomear`.
- Screenshots: `python -m ui --seed 1 --screenshot x.png --cena menu|colecao|colecao_deck|renomear` (tambem `menu_confirmar`, `menu_corrompido`, `resultado`). Geradas em `reports/ui/` (3x, texto conferido em 480x270 sem sobreposicao).
- `python -m ui`, `--run` e o duelo seguem iguais. `pytest`: 1669 passed.

## O que tem
- Menu: Continuar (so com save valido), Novo jogo (confirma se ja ha arquivo), Sair. Save corrompido/ilegivel: aviso vermelho, Continuar desabilitado, Novo jogo disponivel. Falha ao gravar vira toast, nunca derruba.
- Colecao: lista (nome ou raca, raca, sexo, natureza, estrelas IV ATK/HP, ATK/HP finais, estado deck/livre/filh/desc), ordenar por Poder (ATK+HP)/Raca/Nome, filtro de raca (clique cicla), rolagem (roda do mouse, setas, botoes), clique na linha marca/desmarca no deck, "Deck n/12", COMPLETAR (`autofill_deck`), LIMPAR, INICIAR RUN (so com 12; `set_deck` + `new_run_from_save`), detalhe do gato com RENOMEAR (digitar com acentos, Backspace, Enter, Esc, max 16, contador, vazio volta ao padrao).
- Save gravado apos mudar deck, renomear, novo jogo e fim de run. Sem retomar run: fechar a janela no meio = run perdida.
- Fim da run (vitoria, derrota ou abandono): tela "Run encerrada: <resultado>, nos vencidos N" e volta a Colecao. Sem adocao/moedas/breed/filhotes.

## Arquivos (todos em `ui/`)
`hub_controller.py`, `collection_controller.py` (puros, sem pygame), `layout_hub.py`, `render_hub.py`, `scenes_hub.py`, `app_hub.py`; editados: `__main__.py`, `demo.py`, `run_controller.py` (novo parametro opcional `run=` para iniciar com a run da colecao).

## Riscos / pendencias
- Deck parcial (< 12) e gravado atribuindo `save.deck` direto, nao por `set_deck` (que exige 12). O contrato permite, mas se o core passar a validar, precisa de uma API de "rascunho de deck".
- A fonte pixel nao tem alguns caracteres (ex.: n com til, trema em i/e): digita-se mas aparece `?`. O nome salvo fica correto.
- O loop de eventos de `app_hub.py` duplica o de `app_run.py` (mesmo comportamento de duelo/drag); vale unificar depois.
- O hub e a lista de scenes nao tem testes (pasta `tests/` e do agente de testes). Controllers sao testaveis sem pygame (`HubController(content, None, seed)` usa so memoria).
- Colecao com muitos gatos: so 14 linhas visiveis, rolagem testada apenas com 12 gatos (sem rolagem real na tela).
