## Bugs achados
Nenhum bug de regra. Observações:
1. **Backup `.bak` da migração não existe em lugar nenhum.** O core só expõe `save.migrated_from == 1`; `ui/hub_controller.py` só faz `.bak` no Novo Jogo. Ao ler um v1 e regravar (qualquer `write_save`), o arquivo v1 é sobrescrito sem cópia. Testei o protocolo possível (copiar quando `migrated_from == 1`), mas a UI da T13.4 precisa implementá-lo. Caso mínimo: `s = read_save(p_v1); write_save(s, p_v1)` e o v1 se perde.
2. **Prestígio sequencial ignora o nível guardado** (`prestige_reached`): um save com `prestige = 2` guardado, `leagues_cleared = 0` e 5 raças não sobe para 3 ao adotar a 5ª raça. Na prática não ocorre (o 2 só vem da liga vencida, que grava `leagues_cleared`), então não é bug de jogo; só vale saber.
3. Decisões do core que os testes fixam como contrato (ver T13.1): `can_adopt` recusa com gatil exatamente cheio (`occupied == slots`), `can_start_breed` só recusa acima do limite, Prestígio é sequencial, os 12 gatos do deck recebem todo o histórico da run.

## Lacunas
- Posição das decorações (âncoras) e UI (T13.4/T13.5) não são testadas aqui.
- O enforcement é opt-in no core (`enforce_capacity`, `enforce_limits`); os testes passam `True` explicitamente e cobrem o padrão `False` só de passagem. Se o padrão virar `True`, revisar `test_adocao.py` e `test_breed.py`.
