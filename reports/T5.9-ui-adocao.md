# T5.9 - UI: adocao pos-run, doacao, moedas

## O que mudou (so ui/)
- `ui/adoption_controller.py` (novo, sem pygame): usa `adopt`, `donate_offer`, `donation_value`, `cat_stats`, `has_pending_adoption`. Cada decisao grava o save; falha vira aviso.
- `hub_controller.py`: ao fim da run (vitoria, derrota ou abandono="abandono") chama `create_adoption` (rng = `Random(seed*7919 + runs_started)`), UM `write_save`, e abre o modo "adocao". Sem gatos: tela de resultado com "Nenhum gato para adotar desta vez". "Continuar" com `pending_adoption` abre a Adocao antes da coleção. ESC na Adocao volta ao menu (oferta fica no save). Menu mostra "(adoção pendente)".
- Tela de Adocao: 4 cartoes por pagina (paginacao ANT/PROX e roda do mouse), cartoes escondidos ("?") revelados por clique ou REVELAR TODOS; cartao: raca, sexo, natureza e efeito, estrelas IV ATK/HP, ATK/HP/custo, keyword, ADOTAR e DOAR +N. Destaque dourado pulsante para soma >= 8 ("IV ALTO!") e borda branca/dourada para 5/5 ("IV PERFEITO 5/5!"). Moedas no cabeçalho.
- Coleção: MOEDAS no cabeçalho; botão DOAR +N no painel do gato (RENOMEAR ficou mais estreito); confirmação "Doar <nome> por N moedas?"; recusa do core vira "Precisa manter 12 adultos disponíveis."; deck parcial agora usa `save_deck_draft`.
- Cenas/demo: `adocao`, `adocao_vazia`, `doar_confirmar`.

## Como ver
```
python -m ui.demo adocao          (ou adocao_vazia, doar_confirmar)
python -m ui --jogo               (jogo completo; fim da run abre a Adocao)
SDL_VIDEODRIVER=dummy python -m ui --seed 3 --screenshot reports/ui/adocao.png --cena adocao
```
Imagens conferidas (480x270, sem sobreposicao): `reports/ui/adocao.png`, `adocao_vazia.png`, `doar_confirmar.png`.
