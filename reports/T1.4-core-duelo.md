# T1.4 + T1.5 — core do duelo e keywords

## O que mudou
- `core/types.py`: tipos do duelo (Card, DeckSpec, FieldCat, SideState, Duel, Actions, Events, DuelView/SideView, IllegalAction, Side/Winner, `other()`).
- `core/duel.py` (novo): regras, 4 keywords, impasse. Todos os numeros vem de `rules.json` (a unica constante de codigo e o "x2" da Primeira Patada).

## API publica (`from core.duel import ...`; tipos em `core.types`)
- `new_duel(content, rng, player: DeckSpec, enemy: DeckSpec, player_first: bool | None = None) -> Duel` (embaralha player, enemy; dado so se None; mao inicial; inicia turno do primeiro; todos os eventos iniciais ficam em `duel.log`). Deck com gato filhote -> ValueError.
- `legal_actions(duel) -> list[Action]` (vazia se acabou; sempre inclui `EndTurn` enquanto ha jogo).
- `apply_action(duel, action) -> list[Event]` (valida contra `legal_actions`; ilegal -> `IllegalAction` sem tocar estado nem rng; `PlayEffect` sempre ilegal por ora). Eventos tambem sao anexados a `duel.log`.
- `view(duel, side) -> DuelView(side, turn_side, winner, me: SideView, opponent: SideView)`; `SideView(leader_hp, energy, deck_count, hand_count, hand|None, field, turns_taken)`; copia profunda, mao do oponente = `None`.
- `is_over(duel) -> "player" | "enemy" | None`.
- `card_from_cat(content, cat) -> Card`.
- Tipos: `DeckSpec(cats: list[Cat])`; `Card(kind, ref, name, cost, atk, hp, keywords, breed)` (`kind="cat"`, extensivel); `FieldCat(card, atk, hp, hp_max, keywords, ready, used_first_strike)`; `SideState(leader_hp, leader_hp_max, deck (topo=indice 0), hand, field[slots], energy, turns_taken, initial_deck)`; `Duel(content, rng, sides{"player","enemy"}, turn_side, first_side, winner, log)`.
- Acoes: `PlayCat(hand_index, slot)`, `PlayEffect(hand_index, target)`, `Attack(attacker_slot, target)`, `EndTurn()`; target `("slot", n)` / `("leader",)`.
- Eventos: `DiceRolled(first)`, `DrawSkipped(side)`, `Deadlock(powers, first)`, `TurnStarted(side, turn, energy)`, `Drew(side, card)`, `CatPlayed(side, slot, card)`, `EffectPlayed`, `Attacked(side, attacker_slot, target)`, `DamageDealt(side, slot, amount, hp_left)`, `Healed(side, slot, amount, hp_left)`, `CatDied(side, slot, card)`, `LeaderDamaged(side, amount, hp_left)`, `EnergyChanged(side, energy)`, `DuelEnded(winner)`.

## Cenario controlado para testes
`build_duel_for_tests(content, rng=None, *, turn_side="player", player_hand, enemy_hand, player_deck, enemy_deck, player_field: {slot: Cat|Card|FieldCat}, enemy_field, player_energy, enemy_energy, player_leader_hp, enemy_leader_hp, first_turn=False) -> Duel`
- Listas aceitam `Cat` (convertido por `cat_stats`), `Card` ou `FieldCat` (campo). Sem sorteio nem compra inicial.
- Gatos de campo entram `ready=True`. Padrao: os dois lados com 2 turnos jogados (sem restricao de 1o turno; energia padrao = 3); `first_turn=True` poe `turn_side` no seu 1o turno como quem comecou (sem ataque, energia 2).
- Deck inicial (media do impasse) = mao + deck + campo.
- Obs.: o turno do lado nao "comeca" (sem compra) ao montar; para testar fim de turno use `apply_action(d, EndTurn())`.

## Como testar
`pytest -q` (398 passed). Auto-verificacao (scratchpad, nao esta em tests/): 300 seeds de duelos aleatorios, todos terminam com vencedor (4 via impasse), ilegal nao altera estado/rng; cenarios de Provocar, Primeira Patada (dobra so 1x), Robusto, Investida, 1o turno conferidos.

## Decisoes de implementacao a confirmar (nao ambiguas no texto, mas escolhi)
- Ordem do rng em `new_duel`: embaralha player, embaralha enemy, dado (se None).
- Dano em troca entre gatos: o contra-golpe usa o ATK do defensor (sem dobrar); Primeira Patada dobra so o dano de quem ataca; o flag e consumido no 1o ataque da vida, mesmo que seja contra o Lider.
- Impasse: gatilho = nenhum lado tem mao, deck nem gato em campo. Checado apos cada acao e no fim de `new_duel`. Poder = floor((2*soma+n)/(2n)); com deck inicial vazio poder 0 (vale `min_damage`). Eventos do impasse: `Deadlock`, varios `LeaderDamaged`, `DuelEnded`.
- Se o jogador passa o turno sem atacar indefinidamente, nao ha limite de turnos (nao e regra do GDD); IA/sim devem evitar loops.
