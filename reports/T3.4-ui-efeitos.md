# T3.4 - UI: efeitos, Espíritos e inimigo-pessoa

Só `ui/` mudou (mais `reports/`). `pytest -q`: 1086 passam, nenhum teste editado. Fuzz headless (48 duelos com cliques aleatórios + alvos válidos, todos os inimigos reais, deck com efeitos e Espíritos): sem exceção.

## Como ver
- `python -m ui` (sorteia um inimigo real pelo seed) ou `python -m ui --inimigo madame-fifi-pelucia` (ids: tonho-sem-sorte, irmaos-pimenta, berenice-da-matilha, madame-fifi-pelucia). Deck do jogador = 12 gatos sorteados (sem efeitos; para ver efeitos use as cenas).
- Cenas (PNG 3x): `python -m ui --seed 1 --screenshot reports/ui/efeito.png --cena efeito|espirito|chefe`. Geradas: `reports/ui/efeito.png`, `espirito.png`, `chefe.png` e `final_chefe.png` (`--inimigo madame-fifi-pelucia --cena final`). Tudo cabe em 480x270, sem sobreposição além dos rótulos de alvo (iguais ao "ATACAR" antigo).

## O que mudou
- Cartas: efeito = moldura/faixa roxa, custo, nome e resumo curto (`3 DANO / gato inimigo`); Espírito = moldura dourada, etiqueta ESPÍRITO, status fixos, sem estrelas, resumo do "ao entrar". Buff temporário: caixa de ATK dourada com seta, some ao expirar (`atk_bonus_turn`).
- Jogar efeito: clicar na carta e depois no alvo destacado (gato "ALVO", ou Líder "ALVO DO EFEITO"). Sem alvo: clicar na carta de novo ("CLIQUE DE NOVO: USAR"). Espírito: carta, slot; se o "ao entrar" tem alvo, o Espírito fica no slot e pede o alvo; sem alvo válido entra direto com aviso "Sem alvo válido: o efeito ao entrar foi perdido". ESC/botão direito cancela em qualquer etapa. Arrastar também funciona.
- Eventos novos: `EffectPlayed` (pílula com o nome da carta + anel no alvo), `LeaderHealed`, `AtkBuffed`/`AtkBuffExpired` (flutuantes), energia ganha e compra no meio do turno ("+2 ENERGIA", "+1 CARTA"), carta de efeito sai da mão na animação, linhas de log novas.
- Tooltips: efeito (frase completa + texto de sabor), Espírito (ao entrar + sabor + keywords), buff de ATK, e Líder inimigo (nome, tipo, regra própria com descrição).
- Inimigo-pessoa: painel do Líder mostra nome, etiqueta ELITE/CHEFE e "Regra: Banho de Espuma"; painel final mostra uma fala (vitória do inimigo se ele ganhou, derrota se perdeu), sorteada com `Random(seed+2)`. `final_panel` ficou maior (80,36,320,198). "RECÉM-ENTRADO" virou "ENTROU" (estourava o cartão).

## API nova (para testes)
- `Controller(content, seed, *, enemy_id=None, enemy_random=False, player_spec=None)`: `enemy_id` usa `new_duel_vs_enemy`; sem ele, comportamento antigo. Atributos: `enemy` (dict de enemies.json ou None), `final_line`, `line_rng`.
- `sel` ganhou `("enter", hand_i, slot)`. `playable[i]` agora também existe para efeitos (conjunto vazio). `sel_targets` vem de `card_targets` para efeito/Espírito.
- Métodos: `effect_plan(card) -> (lado_gato|None, lado_lider|None)`, `sel_card()`, `targeting()`, `needs_confirm()`, `slot_target(side, n) -> "ATACAR"|"ALVO"|None`, `leader_target(side) -> "attack"|"effect"|None`, `spirit_ghost()`, `enemy_name()`, `_place_card(i, n)`, `_click_card_target(side, target)`.
- `hand_state` de efeito sem alvo: `["SEM ALVO","VÁLIDO"]`; sem energia: motivo de energia.
- `ui.text`: `action_short`, `action_sentence`, `card_summary`, `card_sentences`, `rule_name`, `rule_text`. `ui.render`: `draw_effect_card`, `draw_spirit_ghost`, `leader_tooltip`. `ui.scenes_novas`: `make`, `build`. `ui.app.make_controller(seed, enemy)`.
- Teste antigo `test_cliques_enquanto_o_inimigo_joga_sao_ignorados` já passa (alguém ajustou após T2.4).

## Pendências / dúvidas
- O nome da regra do chefe ("Banho de Espuma") é derivado do `id` (`rule_name`); o data/ não tem campo `nome`/`texto` na `regra_propria`. Sugestão para o agente de dados: adicionar `nome` e `texto`; a UI já os usa se existirem (`nome`; o texto ainda é gerado da ação).
- Textos curtos dos cartões são gerados de `actions` (tipo/alvo/valor), só apresentação. Ação nova no data/ exige entrada em `ui/text.py`.
- A UI lê `alvo` das ações só para saber de que lado destacar; a validade de cada alvo vem sempre de `legal_actions`/`card_targets`.
- Sem testes automáticos dos fluxos novos (agente de testes: `Controller.click` + `settle()`, ver `ui/scenes_novas.py`).
