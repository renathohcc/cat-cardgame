# T4.6 core: recompensas da run

## O que mudou (core/run.py)
- Elite: vitoria abre `drafts_elite` drafts seguidos (padrao 1 se a chave faltar), cada um com `draft_options_elite` opcoes. Status fica "draft" ate acabar a sequencia; so entao volta ao mapa/finaliza.
- Descanso: usa `draft_options_rest` (se ausente, cai em `draft_options`). Batalha comum: `draft_options`.
- Dentro de uma sequencia, o proximo draft nao repete cartas ja escolhidas nela (se o pool restante ainda comporta N opcoes; senao pode repetir).
- API nova: `Run.draft_step` (1-based, 0 fora de draft), `Run.draft_total`, `Run.drafts_left` (drafts por abrir depois do atual). `to_dict` ganhou `drafts_left`, `draft_total`, `draft_taken`, `draft_key`; `from_dict` aceita saves sem esses campos (draft em curso vira total 1).
- `start_duel` em no sem inimigo agora levanta `IllegalAction` (era ValueError).
- `abandon()`: `status == "finished"`, `result == "derrota"` (ja era assim; confirmado). Para o Renatho atualizar em CONTRATOS 2.3.2: tirar "(a confirmar)", citar as chaves `drafts_elite` e `draft_options_rest` e as propriedades acima.
